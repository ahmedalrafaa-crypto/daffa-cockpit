# دفّة — قمرة قيادة الحصة 🧭

تطبيق ويب أوفلاين للتاب: يعرض درس اليوم بطبقتيه (المتن + طبقتك الخاصة)، يدير إيقاع الحصة بمؤقّت مراحل، ويتتبّع تقدّمك عبر السنة مقابل الخطة.

## البنية (الكود مفصول عن البيانات تماماً)

```
DAFFA/
├─ index.html + css/ + js/     ← المُشغّل: كود عرض فقط، صفر محتوى فيزياء
├─ schedule.json               ← خطة السنة: أسابيع كل صف وأنواعها وربطها بالدروس
├─ content/
│  ├─ manifest.json            ← سجل الدروس (المصدر + الصيغة)
│  └─ lessons/*.json           ← ناتج المحوِّل — لا يُحرَّر يدوياً
├─ tools/compile.mjs           ← المحوِّل: يقرأ دروس PHY/PHY6 كما هي
├─ tools/serve.mjs             ← خادم معاينة محلي (للتجربة على الحاسوب فقط)
└─ sw.js + manifest.webmanifest ← PWA: تثبيت على شاشة التاب + عمل أوفلاين
```

## إضافة درس جديد (بلا لمس أي كود)

1. أضف سطراً في `content/manifest.json`:
   ```json
   { "id": "g9-ch1-l7", "grade": "g9", "format": "phy-v1",
     "source": "../PHY/chapters/ch1/lesson7.html", "title": "المجال الكهربائي" }
   ```
   (دروس السادس: `"format": "phy6-v1"` و `"source": "../PHY6/lessons/..."`)
2. شغّل من مجلد DAFFA:  `node tools/compile.mjs`
3. اربط الدرس بأسبوعه في `schedule.json` (حقل `lessons`).
4. أضف ملف الدرس الجديد إلى قائمة `PRECACHE` في `sw.js` وغيّر رقم `VERSION` (مثل `daffa-v3`) ليصل التحديث للتاب.

## التجربة على الحاسوب

- **من الفولدر مباشرة**: انقر `index.html` نقرتين — يعمل فوراً (البيانات محمّلة من `content/bundle.js`).
- أو عبر خادم محلي: `node tools/serve.mjs` ثم افتح http://localhost:8390

## النقل إلى التاب بالنسخ المباشر (بلا نت نهائياً)

انسخ مجلد DAFFA كاملاً إلى ذاكرة التاب وافتح `index.html` من مدير الملفات بمتصفح كروم — يعمل بالكامل.
ملاحظة: بهذه الطريقة لا يُثبَّت كأيقونة تطبيق على الشاشة الرئيسية؛ التثبيت الأنيق يحتاج طريقة GitHub Pages أدناه (مرة واحدة بالنت).

## التثبيت على التاب (مرة واحدة بالنت، ثم أوفلاين للأبد)

1. ارفع مجلد DAFFA إلى GitHub Pages (مستودع جديد → Settings → Pages → deploy from main).
2. افتح الرابط على متصفح التاب (كروم) → قائمة ⋮ → **إضافة إلى الشاشة الرئيسية**.
3. من تلك اللحظة يعمل التطبيق بلا إنترنت إطلاقاً؛ وأي تحديث ترفعه يصل تلقائياً عند أول اتصال.

## نسخ احتياطي

تقدّمك وملاحظاتك تعيش داخل التاب (localStorage). من ⚙️ الإعدادات → **تصدير JSON** خذ نسخة دورياً، و**استيراد JSON** يستعيدها على أي جهاز.

## قاعدة المحتوى

المحوِّل لا يختلق شيئاً: كل ما يظهر بالتطبيق منسوخ حرفياً من `PHY/` و `PHY6/`.
الدروس غير المحوَّلة تظهر كقالب فارغ معلَّم بوضوح 📦 حتى تُحوِّلها بنفسك.
